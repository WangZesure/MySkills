# Lineage Research（线调研）：锚点论文 → 发展脉络

## 方法总览

引用图的双向遍历：**references（向后）= 思想根源**，**citations（向前）= 发展演进**。
从一篇锚点论文出发，反复向两个方向扩展，整理成带时间线的脉络。
与"点调研"互补：点调研定位"最接近的工作"，线调研摸清"这条线怎么走到今天"。

## 流程

1. **锚点**：确定一篇关键论文（通常来自点调研结果，如命中 ★★★ 的那篇）。
2. **向后（根源）**：查它的 references，筛选"同类方法"（排除 CLIP/Adam 等基础设施引用）。
3. **向前（演进）**：查它的 citations，筛选"方法延续/改进"（排除纯应用、纯 benchmark）。
4. **迭代**：对重要节点再展开一轮（扩展深度 ≤2，避免图爆炸）。
5. **组织**：按年份排时间线，每个节点一句话——解决了什么问题、相对锚点新增什么。
6. **输出**：文本脉络图 + 各代代表性论文 + 该方向当前开放问题。

## 工具

- **Semantic Scholar API**（免费、无 key 可限量调用）：
  - 引文（根源）：`/graph/v1/paper/arXiv:ID/references?fields=title,year,abstract`
  - 被引（演进）：`/graph/v1/paper/arXiv:ID/citations?fields=title,year,abstract`
- 批量脚本：`scripts/ss_graph.py`（代理 + 限流退避 + 关键词筛选 + 时间线排序）。
- 备选：Connected Papers（网页）、OpenAlex API（引用更全但需处理格式）。

## 筛选准则

| 维度 | 保留 | 排除 |
|---|---|---|
| references | 方法同源 / 同机制 / 同任务 | CLIP、Adam、数据集这类基础设施 |
| citations | 直接改进 / 对比该方法 | 纯应用、纯 benchmark、综述里的顺带引用 |

每个保留节点一句话标注：**年份 + 解决了什么问题 + 相对锚点的新增**。

## 停止条件

- 时间线已覆盖该方向主要节点（每代 2-3 篇代表）；
- 扩展深度 ≥2 层后，新节点不再有机制性差异；
- 碰到"尽头"（早期方法无引用、最新方法无被引）。

## 输出模板

```markdown
## <方向名> 发展脉络（锚点：<论文>）
### 根源（references，向后）
年份 → 方法名 → 贡献一句话 → 与锚点关系
### 演进（citations，向前）
年份 → 方法名 → 贡献一句话 → 相对锚点的新增
### 时间线图（文本）
2022: ... → 2023: ... → 2024: ... → 2025: ... → 2026: ...
### 开放问题
```

## 与点调研的衔接

线调研的起点 = 点调研的 ★★★ 命中；线调研产出的"开放问题"可回喂给点调研，
作为下一轮"由近及远"的新 idea 起点。
